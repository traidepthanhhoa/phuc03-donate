SETUP

Cách dùng

1. Mở card script bạn muốn và chọn View Content để xem nội dung.
2. Nhấn Copy Script để chép toàn bộ nội dung vào clipboard.
3. Thêm script mới bằng cách chỉnh mảng SCRIPTS trong file script.js.
4. Đổi trạng thái trong MAINTENANCE_MODE: true = tắt script, false = bật script.
